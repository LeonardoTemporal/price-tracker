# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.1.x   | Yes       |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

Please report security vulnerabilities to **pricy.pricetracker@gmail.com**.

We will respond within 48 hours and work with you to resolve the issue responsibly.
